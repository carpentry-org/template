MyMod

is a template module you should replace with your own.

Installation

(load "git@github.com:your-user/your-project@0.1.0")

Usage

(MyMod.greet "Carp") ; => "Hello, Carp!"

This file is named after the module it holds (MyMod lives in my-mod.carp), which is the convention the carpentry-org packages follow. When you rename it, rename test/my-mod.carp with it and update the paths in gendocs.carp and .github/workflows/ci.yml.
